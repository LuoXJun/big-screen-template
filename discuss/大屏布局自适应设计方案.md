# 大屏布局自适应设计方案

> 状态：已实施 v4（双图层流式 + clamp 限幅自适应）｜适用范围：base-screen-template（Vue 3.5 + Vite 8 + TS + Cesium 1.131 + ECharts）

## 1. 项目现状

| 项 | 现状 |
| --- | --- |
| 框架 | Vue 3.5 + Vite 8 + TS + pnpm |
| 地图 | Cesium 1.131（高德瓦片免 token 底图） |
| 图表 | ECharts 5（按需引入，BaseChart 封装） |
| 布局 | **双图层流式**：地图层真实尺寸弹性填充；UI 层流式排布 + clamp 限幅自适应（无整体缩放） |

## 2. 需求分析

- 兼容各种显示器：1366×768 笔记本、1080p、2K、4K、21:9 超宽屏、16:10 等
- 内容含 ECharts 图表 + Cesium 地图（均 canvas 渲染）
- **核心认识**：Cesium 地图与页面 UI 是两套完全独立的模块
- **演进动因**：v3（UI 舞台整体 scale）在非 1920×1080 屏上"缩小太狠 / 放大太傻"——严格等比与"每个屏幕都看起来合适"矛盾。v4 改为**模块化自适应**：组件流式布局，尺寸与字号由 `clamp()` 限幅随视口变化（1920×1080 为设计基准），不整体缩放。

## 3. 方案演进

| 版本 | 方案 | 问题 |
| --- | --- | --- |
| v1 | 整屏 transform scale | 顶部不满宽、面板漂移、地图模糊、事件遮挡 |
| v2 | 全流式（固定像素） | 面板不缩放，多尺寸视觉占比不一致 |
| v3 | 地图弹性 + UI 舞台 scale | 非 1080p 屏 UI 过小/过大，仍依赖整体缩放 |
| **v4（已实施）** | **地图弹性 + UI 流式 + clamp 限幅** | 小屏保可读性下限、大屏不臃肿，各尺寸"合适" ✅ |

## 4. 布局结构（双图层流式框架）

```
.screen-layout（100vw × 100vh，relative）
├── .map-layer（absolute inset-0）      ← Cesium 真实尺寸 100%，独立自适应
└── .ui-layer（absolute inset-0，flex column，事件穿透）
    ├── ScreenHeader（100% 宽，高度 clamp(56px, 4.17vw, 88px)）
    ├── .layout-body（flex row，gap/padding clamp）
    │   ├── 左面板（width: clamp(280px, 17.7vw, 460px)）
    │   ├── .main-gap（中央空隙，露出地图，事件穿透）
    │   └── 右面板（同上）
    └── ScreenFooter（100% 宽，高度 clamp(40px, 2.9vw, 64px)）
```

- 五插槽（`#map` + `#header/#left/#right/#footer`），业务页面按插槽组装
- 事件穿透：`ui-layer` / `layout-body` / `main-gap` 均 `pointer-events: none`，只有 ScreenPanel 等具体组件自身 `auto`——地图交互不受遮挡

## 5. 自适应体系（:root CSS 变量）：等效视口等比 + 字号限幅

### 5.1 核心：`--screen-base`（等效 16:9 视口宽度）

```scss
:root {
    /* 16:9 系屏 = 100vw（等比放大）；窄屏/超宽屏按高度折算，
       UI 等比居中，留白区域露出地图 */
    --screen-base: min(100vw, calc(100vh * 1.7778));
}
```

**所有尺寸 = base × 设计稿占比**，宽高同基准 → 任意尺寸下 UI 等比不变形（修复"面板拉长"问题）：

| 尺寸 | 公式 | 基准（1920） |
| --- | --- | --- |
| 面板宽度 | `calc(var(--screen-base) * 0.1771)` | 340px |
| Header 高 | `calc(var(--screen-base) * 0.04167)` | 80px |
| Footer 高 | `calc(var(--screen-base) * 0.02917)` | 56px |
| `--space-screen` 布局间距 | `calc(var(--screen-base) * 0.00729)` | 14px |
| `--space-panel` 面板内边距 | `calc(var(--screen-base) * 0.00625)` | 12px |

> 面板高度为 flex 弹性（Header/Footer/间距等比后，剩余空间自然等比），面板宽高比在所有尺寸下严格一致（1:1.326）。

### 5.2 字号：clamp 限幅（中值随 base 等比）

| 变量 | 公式 | 基准 | 1366 | 3840 |
| --- | --- | --- | --- | --- |
| `--font-hero` | `clamp(22px, calc(var(--screen-base) * 0.01875), 40px)` | 36px | 22 | 40 |
| `--font-panel` | `clamp(13px, calc(var(--screen-base) * 0.00833), 17px)` | 16px | 13 | 17 |
| `--font-body` | `clamp(11px, calc(var(--screen-base) * 0.00677), 15px)` | 13px | 11 | 15 |
| `--font-small` | `clamp(10px, calc(var(--screen-base) * 0.00625), 13px)` | 12px | 10 | 13 |

组件使用 CSS 变量（`font-size: var(--font-hero)`），新增组件沿用同一体系即可。

## 6. 组件实现

### 6.1 ScreenLayout

纯流式框架（无任何 transform scale / 无 JS 缩放模块），布局职责与自适应职责分离到 CSS。

### 6.2 ECharts（BaseChart）

- 图表容器随流式布局自适应（面板宽度/高度变化）→ **ResizeObserver 监听容器，150ms 防抖后 `chart.resize()`**
- 统一封装 click / hover 事件，透出强类型载荷
- 图表内部文字为固定 px（ECharts 特性）；如需随容器缩放，可用 ECharts `media` 配置按容器宽度切换 option（见第 8 节演进）

### 6.3 Cesium（BaseCesium）

- 地图层真实尺寸，零缩放逻辑：容器自适应、拾取直接用事件坐标、无分辨率联动
- 暴露 `flyToCity` 相机飞行；底图高德路网瓦片（免 token）；示例实体点位

## 7. 各分辨率效果

| 屏幕 | base | 地图层 | UI 层 |
| --- | --- | --- | --- |
| 1920×1080 | 1920 | 中央地图 | 设计稿原值（面板 340×451、标题 36px），1:1 |
| 1366×768 | 1365 | 缩窄填充 | 面板 242×321（等比）、标题 22px |
| 2560×1440 | 2560 | 加宽填充 | 面板 453×602（等比 1.333 倍）、标题 ~40px |
| 3840×2160 (4K) | 3840 | 超宽填充，原生清晰 | 面板 680×902（等比 2 倍）、标题 40px（限幅） |
| 3440×1440 (21:9) | 2560 | 极宽填充 | UI 等比 1.333 倍居中，两侧留白露出地图 |
| 1920×1200 (16:10) | 2133 | 上下加高填充 | UI 等比 1.111 倍居中，上下留白露出地图 |

> **面板宽高比在所有尺寸下严格一致（1:1.326）**——任意屏幕、任意窗口尺寸切换，UI 等比变化，不会拉长变形；地图层吸收全部变化。
